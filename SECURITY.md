# Security reporting

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/chrwittm/egg-cooker/security/advisories/new). Do not publish sensitive vulnerability details, credentials, or private user data in a public issue.

Egg Cooker is an experimental project without a guaranteed response time, bounty, or long-term support commitment. Security fixes target the latest published version when practical; older versions are not maintained unless a release note says otherwise.

For maintainers, see the [security and privacy runbook](docs/operations/security-privacy.md).
